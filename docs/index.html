One serve command, shared routing.

Serve mode composes the HTTP forward proxy, SOCKS5 listener, and transparent TUN ingress around one route table and provider map. Disable TUN when you only need application proxying.

HTTP and SOCKS5

Give applications a familiar proxy endpoint while unmatched destinations continue over the local network.

Transparent TUN

Apply the same route decisions to system traffic where the platform and required privileges support a TUN device.

Ordered failover

Prefer the first configured provider, skip unhealthy nodes, and try the next candidate for new connections.

Provider readiness

Health checks that stay out of the data path.

Tunny sends a small PING through the configured node transport. A ready provider answers PONG. Thresholds keep temporary network noise from flapping routes.

  • Healthy eligible for new connections
  • Unhealthy skipped after repeated failures
  • Recovered restored after repeated successes
route_policies:
  example.com:
    mode: failover
    providers: [japan, singapore]

health:
  enabled: true
  interval: 5s
  timeout: 2s
  failure_threshold: 2
  recovery_threshold: 3
